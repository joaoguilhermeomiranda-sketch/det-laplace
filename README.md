# Determinante por Laplace

Implementação em **Python** para calcular o determinante de matrizes quadradas utilizando o **Teorema de Laplace**.

O projeto utiliza recursividade para reduzir a matriz até os casos básicos de `1×1` e `2×2`.

## Funcionalidades

- Cálculo de determinantes por expansão de Laplace
- Geração de matrizes aleatórias
- Entrada manual de matrizes
- Exibição da matriz utilizada
- Sem bibliotecas externas

## Como executar

É necessário ter o **Python 3** instalado.

```bash
python main.py
```

Depois, escolha entre gerar uma matriz aleatória ou inserir os valores manualmente.

## Exemplo

```text
Matriz utilizada:
  2   4   1
  3   5   2
  1   2   3

Determinante da matriz: -3
```

# Laplace Determinant

A **Python** implementation for calculating the determinant of square matrices using the **Laplace Expansion Theorem**.

The project uses recursion to reduce the matrix until reaching the basic `1×1` and `2×2` cases.

## Features

- Determinant calculation using Laplace expansion
- Random matrix generation
- Manual matrix input
- Displays the matrix used
- No external libraries

## How to Run

**Python 3** is required.

```bash
python main.py
```

Then, choose between generating a random matrix or entering the values manually.

## Example

```text
Matrix:
  2   4   1
  3   5   2
  1   2   3

Matrix determinant: -3
```
